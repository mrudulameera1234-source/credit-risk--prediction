# Credit Risk Prediction System

An end-to-end Machine Learning web application designed to evaluate loan applications and predict credit risk based on historical borrower data.

## 📌 Project Overview
This project processes customer financial parameters to classify credit applicants as high or low risk. It features a trained ML classification model integrated into an interactive web interface.

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python
* **Machine Learning:** Scikit-Learn, Pandas, NumPy
* **Model Serialization:** Joblib / Pickle
* **Web Framework:** Flask / HTML & CSS
* **Database:** MySQL

## ✨ Key Features
* User application input form for financial details.
* Automated feature preprocessing and scaling.
* Real-time risk probability calculation using the trained model.
* Clean web dashboard to review predictions and loan history.
